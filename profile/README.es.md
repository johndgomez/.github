**Diseño y evolución de software empresarial**

La práctica profesional de [John D. Gómez](https://github.com/johndgomezh), centrada en el diseño de software, las integraciones empresariales y la evolución de sistemas que sostienen la operación de un negocio.

## Dónde comienza el trabajo

**Una decisión de diseño con consecuencias importantes.** Examinar responsabilidades, dependencias y alternativas de implementación antes de comprometer una dirección.

**Una integración entre sistemas de negocio.** Precisar contratos de información, responsables y recuperación cuando sólo una parte del proceso termina correctamente.

**Un sistema existente que necesita evolucionar.** Planificar cambios graduales considerando pruebas, entrega, mantenibilidad y continuidad operativa.
