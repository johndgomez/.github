**Enterprise software design and evolution**

Technical projects and publications by [John D. Gómez](https://github.com/johndgomezh), focused on software design, systems integration and the evolution of software that supports business operations.

## Areas of work

**Design decisions.** Responsibilities, dependencies and implementation options, with the reasons and constraints behind a choice.

**Systems integration.** Information contracts and recovery when only part of a workflow succeeds.

**System evolution.** Incremental changes supported by testing, maintainability and operational continuity.
